# 3. 파일로 주고받기

[목차](README.md) · 이전: [2.15 변경분을 SQL 스크립트로 내보내기](comments-script.md) · 다음: [3.2 가져오기](import.md)

파일로 내보내는 기능은 두 가지다. 용도가 다르다.

| | 내보내기 · 가져오기 | 정의서 내보내기 |
|---|---|---|
| 용도 | 엑셀에서 고친 뒤 다시 가져오기 | 사람이 읽는 제출용 문서 |
| 양식 | 시트 한 장, 6칸 | 개체당 시트 한 장 + 목록 시트, 표제부 포함 |
| 범위 | 지금 문서에 읽어 온 것 | 목록에서 체크한 개체 |
| 다시 가져오기 | 된다 | 안 된다 |

이름 몇 개를 한 열만 고칠 때는 파일을 오가지 않아도 된다. Excel에서 열을 복사해 코멘트 그리드에 바로 붙여넣는
편이 빠르다([2.8](comments-fill.md#28-excel에서-붙여넣기)). 파일 가져오기는 여러 칸·많은 행을 한꺼번에 고쳐 다시 넣을 때 쓴다.

## 3.1 내보내기

내보내기·가져오기는 모든 코멘트 문서에 있다 — 분류 폴더의 `코멘트 관리` 문서, 테이블·뷰·루틴·타입 문서, 같은 컬럼명 문서.
작성률 문서와 저장 이력 문서는 읽기 전용이라 이 기능이 없다(작성률 문서의 Excel 보고서는 [2.12](comments-review.md#212-작성률-보기)를 볼 것).

여는 곳은 셋이다. 어느 것이든 같은 흐름이다.

| 여는 곳 | 방법 |
|---|---|
| 문서 툴바 | 코멘트 문서 위쪽의 **내보내기** |
| 메뉴 | 코멘트 문서가 활성 탭일 때 **문서 > 내보내기...** |
| DB 탐색기 | 폴더나 개체를 오른쪽 클릭하고 **내보내기...** — 그 노드의 문서를 열고(이미 열려 있으면 그 탭) 다 읽은 뒤 시작한다 |

1. 저장 창에서 파일 이름과 위치를 고른다.
2. 파일 이름이 `.xlsx`로 끝나면 Excel, 그 밖은 CSV로 저장한다. CSV는 엑셀에서 한글이 깨지지 않게 UTF-8(BOM)로 쓴다.
   **Excel에서 고칠 파일은 `.xlsx`로 내보낸다.** CSV를 Excel로 열면 `- 항목`, `=합계`처럼 `-`·`=`·`+`·`@`로 시작하는 값이 수식으로 바뀌어
   `#NAME?`이 될 수 있다. 그런 값이 있는 채로 CSV를 내보내면 상태줄이 알려 준다.
3. 끝나면 저장한 파일 경로가 출력 창에 남는다.

- 칸은 `개체유형 · 스키마 · 상위개체 · 개체명 · 이름 · 설명`이다. `개체유형`은 `Table`, `Column`, `Procedure` 같은 영문 이름이다.
- 예전 버전이 내보낸 파일(머리글 `이름 · 한글명`)도 그대로 가져온다.
- 지금 문서에 읽어 온 범위만 내보낸다. 저장하지 않은 편집도 들어간다.
- `미작성만`·`변경만`이나 검색으로 걸러 둔 상태여도 문서의 전체 항목을 내보낸다. 보이는 행만 내보내려면 아래 방법을 쓴다.

### 보이는 행만 내보내기

미작성 행만 걸러 담당자에게 넘길 때 쓴다.

1. 코멘트 그리드를 `미작성만`·`변경만`·검색으로 좁힌다.
2. 그리드를 오른쪽 클릭 > `보이는 행 내보내기...`. 보이는 행이 없으면 꺼져 있다.
3. 저장 창의 기본 이름 뒤에 `_일부`가 붙는다. 형식과 칸은 위 내보내기와 같다.

- 그 그리드에 지금 보이는 행만 담는다. 개체 문서의 머리글(개체 자신)과 다른 탭의 목록은 넣지 않는다.
- 담당자가 채운 파일은 그대로 [가져오기](import.md#32-가져오기)로 받는다.
