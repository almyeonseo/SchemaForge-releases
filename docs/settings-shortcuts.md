# 5. 설정과 단축키

[목차](README.md) · 이전: [4. SQL 편집기](sql-editor.md) · 다음: [6. 문제 해결](troubleshooting.md)

## 5.1 설정

**파일 > 설정...**(`Ctrl+,`)으로 연다.

| 항목 | 기본값 | 언제 반영되나 |
|---|---|---|
| 테마 (시스템 설정 따르기 · 라이트 · 다크) | 시스템 설정 따르기 | 고르는 즉시. 취소하면 되돌아간다 |
| 앱을 켤 때 시작 페이지 표시 | 켬 | 다음 실행부터 |
| 앱을 켤 때 업데이트 확인 | 켬 | 다음 실행부터 |
| 새 탭의 확대 비율 | 100 % | 다음에 여는 SQL 편집기 탭부터 |
| 결과 행 상한 | 100,000행 | 다음 실행부터. 이미 열린 탭에도 적용된다 |
| 실행 시간 제한 | 60초 | 다음 실행부터. 이미 열린 탭에도 적용된다 |

- 행 상한과 시간 제한은 **무제한**으로 둘 수 있다. 행 상한을 풀고 큰 테이블을 전부 조회하면 앱이 멈추거나 메모리 부족으로 꺼질 수 있다.
- **기본값으로**는 화면의 값만 바꾼다. **확인**을 눌러야 저장된다.
- 테마는 **보기 > 테마** 메뉴에서도 바꾼다. `Ctrl+T`는 라이트와 다크를 오간다.

## 5.2 단축키

macOS에서는 `Ctrl`을 `Cmd`로 누른다(예: `Cmd+S`). 종료는 `Cmd+Q`다. 앱 안에서는
**도움말 > 단축키 목록**으로 지금 OS에 맞는 표를 볼 수 있다.

### 어디서나

| 단축키 | 동작 |
|---|---|
| `Ctrl+N` | 새 쿼리 (DB 탐색기에서 고른 연결) |
| `Ctrl+O` | 쿼리 파일 열기 |
| `Ctrl+Shift+N` | 새 DB 연결 |
| `Ctrl+S` | 저장. 코멘트 문서는 DB에, SQL 편집기는 파일로 |
| `Ctrl+Shift+S` | 모두 저장 (열린 탭 중 변경이 있는 것) |
| `Ctrl+W` | 지금 탭 닫기 |
| `Ctrl+,` | 설정 |
| `F1` | 사용 설명서 (이 문서) |
| `Ctrl+T` | 라이트 ↔ 다크 테마 |
| `F8` / `Shift+F8` | 다음 / 이전 미작성 항목 (코멘트 문서) |
| `F5` · `Ctrl+Enter` | SQL 실행 (SQL 편집기 탭) |
| `Ctrl+.` | SQL 실행 중단 (SQL 편집기 탭) |

`F5`는 DB 탐색기에 포커스가 있으면 실행이 아니라 탐색기 새로고침이다. 어디에 포커스가 있든 실행하려면 `Ctrl+Enter`를 쓴다.

### 코멘트 문서의 그리드에서

| 키 | 동작 |
|---|---|
| `F2` 또는 고른 칸을 한 번 더 클릭 | 입력 시작 |
| `Tab` | 값을 넣고 옆 칸으로 (입력 상태 유지) |
| `Enter` | 입력을 끝내고 아래 행으로 |

### SQL 편집기 안에서

| 키 | 동작 |
|---|---|
| `Ctrl+F` | 찾기 |
| `F3` / `Shift+F3` | 다음 / 이전 찾기 |
| `Esc` | 찾기 닫기 |
| `Ctrl+K`, `Ctrl+C` / `Ctrl+K`, `Ctrl+U` | 고른 줄 주석 처리 / 주석 해제 |
| `Ctrl+C` / `Ctrl+Shift+C` | 결과 표에서 고른 줄 복사 / 칸 이름까지 복사 |

### 정의서 내보내기 창에서

| 키 | 동작 |
|---|---|
| `Space` | 고른 줄 체크 / 해제 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 분류 탭 (macOS에서도 `Control`) |
| `Esc` | 검색어가 있으면 지우고, 없으면 창 닫기 |

### DB 탐색기에서

| 키 | 동작 |
|---|---|
| `F5` | 연결 목록 새로고침 |
| 메뉴 키 · `Shift+F10` | 오른쪽 클릭 메뉴 |
