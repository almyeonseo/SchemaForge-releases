# 5. 설정과 단축키

[목차](README.md) · 이전: [4. SQL 편집기](sql-editor.md) · 다음: [6. 문제 해결](troubleshooting.md)

## 5.1 설정

**파일 > 설정...**(`Ctrl+,`, macOS `Cmd+,`)으로 연다. 창은 `일반`과 `SQL 편집기` 두 묶음이다.

| 묶음 | 항목 | 기본값 | 언제 반영되나 |
|---|---|---|---|
| 일반 | 테마 (시스템 설정 따르기 · 라이트 · 다크) | 시스템 설정 따르기 | 고르는 즉시. 취소하면 되돌아간다 |
| 일반 | 화면 글꼴 (설치된 글꼴) | 기본(Inter + OS 한글 글꼴) | 고르는 즉시. 취소하면 되돌아간다 |
| 일반 | 화면 글자 크기 (12~18) | 14 | 고르는 즉시. 버튼·입력칸 높이도 함께 바뀐다. 취소하면 되돌아간다 |
| 일반 | 앱을 켤 때 시작 페이지 표시 | 켬 | 다음 실행부터 |
| 일반 | 앱을 켤 때 업데이트 확인 | 켬 | 다음 실행부터. **도움말 > 업데이트 확인**은 설정과 상관없이 언제나 된다 |
| 일반 | 앱을 켤 때 지난번 SQL 편집기 탭 다시 열기 | 켬 | 다음 실행부터. 파일로 저장한 탭만 다시 열고 실행하지는 않는다([4.9](sql-editor.md#49-파일로-저장지난-탭)) |
| SQL 편집기 | 코드 글꼴 (설치된 고정폭 글꼴) | D2Coding(앱에 들어 있음) | 고르는 즉시. 취소하면 되돌아간다 |
| SQL 편집기 | 코드 글자 크기 (10~24) | 13 | 고르는 즉시. 열린 편집기도 탭마다의 확대 비율을 둔 채 바뀐다. 취소하면 되돌아간다 |
| SQL 편집기 | 결과 행 상한 | 무제한 (무제한을 끄면 100,000행이 채워진다) | 다음 실행부터. 이미 열린 탭에도 적용된다 |
| SQL 편집기 | 실행 시간 제한 | 무제한 (무제한을 끄면 60초가 채워진다) | 다음 실행부터. 이미 열린 탭에도 적용된다 |

- 행 상한과 시간 제한은 기본이 **무제한**이다. 큰 테이블을 자주 조회한다면 행 상한을 걸어 둘 것 — 수백만 행을 통째로 받으면 앱이 멈추거나 메모리 부족으로 꺼질 수 있다.
- 행 상한과 시간 제한 칸에는 1 이상의 정수를 적는다. 천 단위 쉼표(`100,000`)는 세 자리마다 찍은 것만 받는다. 잘못 적으면 칸 아래에 이유가 보이고 **확인**이 꺼진다.
- 항목마다 아래에 언제 반영되는지가 적혀 있다.
- **코드 글꼴과 코드 글자 크기**는 SQL 편집기, 값 보기 창, 결과의 메시지 탭, 출력 창에 함께 걸린다. 기본 코드 글꼴 D2Coding은 한글이 영문 두 칸
  폭이라 한글 주석·문자열이 섞인 SQL 줄도 세로로 줄이 맞는다. SQL 편집기 탭에서 확대·축소한 비율은 탭마다 따로 남고 새 탭은 100%로 시작한다.
- 저장한 글꼴이 이 PC에 없으면(다른 PC에서 옮겨 온 설정 등) 기본 글꼴로 열고 출력 창에 알린다.
- 예전 버전에서 `새 탭의 확대 비율`을 바꿔 두었으면 그에 맞는 코드 글자 크기로 옮겨 온다(예: 150% → 20).
- **기본값으로**는 화면의 값만 바꾼다. **확인**(또는 `Enter`)을 눌러야 저장된다. **취소**·`Esc`·창 닫기는 창을 열기 전 상태로 되돌린다.
- 테마는 **보기 > 테마** 메뉴에서도 바꾼다. `Ctrl+T`(macOS `Cmd+T`)는 지금 보이는 테마의 반대(라이트 ↔ 다크)를 고른다. 어느 쪽에서 바꿔도 저장된다.

## 5.2 단축키

앱 안에서는 **도움말 > 단축키 목록**으로 지금 OS에 맞는 표를 볼 수 있다.
macOS에서는 대개 `Ctrl` 자리를 `Cmd`로 누른다. 다른 점은 아래 표의 macOS 칸에 적었다.

- 종료는 `Cmd+Q`, 바꾸기는 `Cmd+Option+F`다(`Cmd+H`는 macOS에서 앱 숨기기다).
- `Alt`는 `Option`이다.
- `Tab`이 든 키는 macOS에서도 `Control`이다. `Cmd+Tab`은 macOS가 앱 전환에 쓴다.
- `Ctrl+K, Ctrl+C`처럼 쉼표로 이은 키는 앞 키를 누른 뒤 뒤 키를 누르는 두 번 누르기다.

### 어디서나

| 동작 | Windows·Linux | macOS |
|---|---|---|
| 새 쿼리 — DB 탐색기에서 고른 연결 | `Ctrl+N` | `Cmd+N` |
| 쿼리 파일 열기 — DB 탐색기에서 고른 연결 | `Ctrl+O` | `Cmd+O` |

| 모두 저장 — 열린 탭의 코멘트 문서와 SQL 편집기 | `Ctrl+Shift+S` | `Cmd+Shift+S` |
| 현재 탭 닫기 | `Ctrl+W` | `Cmd+W` |
| 라이트·다크 테마 바꾸기 | `Ctrl+T` | `Cmd+T` |
| 설정 | `Ctrl+,` | `Cmd+,` |
| 사용 설명서 열기 | `F1` | `F1` |

| SQL 실행 — DB 탐색기에 포커스가 있어도 실행 | `Ctrl+Enter` | `Cmd+Enter` |
